
POS CRUD API SYSTEM


A POS (Point-of-sale)  application is an application that is used  to conduct and manage sales transactions of a business.
This application often works with the use of hardware devices  like barcode scanners and receipt printers.

TYPE OF BUSINESS THIS SYSTEM IS DESIGNED FOR
Inventory management: tracking items that have been sold and what is in stock.
Transaction processing: process of sales transactions.
Sales reporting and analytics: collection and presentation of data on sales trends, popular products, and peak transaction days and times.
Customer management: keeping track of customer data, which includes history and preferences.
Employee management and tracking: keeping track of employee performance like work logging hours and sales targets.

MAIN FEATURES THE POS WILL SUPPORT
Transaction initiation and price calculation
Payment selection,confirmation and initiation
Inventory adjustments and sales data adjustments
Data backup and end-of-day reconciliation

IT HAS THE FOLLOWING ENTITIES
Product,
Customer,
User,
Sale,
Sale Item,
Payment,
Category,
Supplier,
Receipt.
